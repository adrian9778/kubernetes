## 20.2 术语

- Reconcile：比较期望和观察状态并执行收敛。
- Informer：共享 List-Watch、本地缓存和事件分发。
- Lister：只读访问 Informer cache。
- Tombstone：删除事件中最后对象未知的包装。
- Assume：API 持久化前在本地乐观占用。
- Finalizer：对象删除前必须完成的清理责任。
- OwnerReference：GC 依赖关系。
- Strategy：API 资源 create/update/delete 的特有规则。
- Subresource：独立路由、权限和策略的资源视图。
- FeatureGate：按版本控制能力启用状态，不等于 API 稳定性。
- DRA：Dynamic Resource Allocation，结构化设备发现与分配。

## 20.4 实现验收

读者应能独立实现：带 CAS/watch 的对象存储；断线恢复 Informer；去重限速队列；幂等 Replica Controller；Assume/Bind Scheduler；UID 串行 Node Agent；desired/actual Volume reconciler；事务化 Service rule compiler。

## 20.5 阅读完成标准

对任意核心 struct，能画出创建者、持有者、输入、锁、goroutines、停止方式；对任意 API 写，能说明外部版本到 storage version；对任意控制器错误，能判断重试、等待新事件或写 condition；对任意故障，能从对象状态定位到唯一组件边界。
